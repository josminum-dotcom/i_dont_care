# i_dont_care

A minimal C# console application.

## Getting started

1. Install the [.NET 8 SDK](https://dotnet.microsoft.com/download).
2. Navigate to the project folder:
   ```bash
   cd src/I_Dont_Care
   ```
3. Run the app (optionally passing a name to greet):
   ```bash
   dotnet run -- "Your Name"
   ```

The app will print a friendly greeting to the console.
